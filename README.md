# DramaVault

A free streaming site for Asian dramas, movies, TV series, and short plays.

## Features
- 🎬 Browse Movies, TV Series, and Short Plays
- 🔍 Search by title or cast name
- 👤 View cast profiles with full filmography
- ▶️ Watch episodes with embedded video player (YouTube, Vimeo, direct MP4)
- 🎨 Minimalist dark theme

## Tech Stack
- React + TypeScript
- Vite
- Tailwind CSS

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Deploy to Vercel

1. Push to GitHub
2. Import repo at [vercel.com](https://vercel.com)
3. Click Deploy — done!
